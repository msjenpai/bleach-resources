# Bleach Resources

Bleach Resources is a community-developed collection of Foundry VTT tools, compendiums, automation, UI improvements, and game resources designed for use with the **Soul Society 5e** Bleach tabletop ruleset.

The goal of this project is to make running Bleach-inspired campaigns in Foundry VTT easier by reducing repetitive setup, organizing large amounts of game content, and automating mechanics where practical.

---

## Compatibility

Current development target:

- **Foundry VTT:** v14 Build 368
- **Game System:** D&D5e 6.0.5
- **Ruleset:** Soul Society 5e
- **Project Status:** Active Development

Compatibility with other Foundry or D&D5e versions is not guaranteed.

---

## Features

Bleach Resources currently includes or is being developed to include:

### Compendiums

- Kidō
- Zanjutsu
- Hakuda
- Hohō
- Shinigami features
- Zanpakutō-related content
- Additional Soul Society 5e content

### Foundry Integration

- Reiryoku resource tracking
- Stamina resource tracking
- Character sheet resource displays
- Automated resource consumption
- Attack and damage workflows
- Active Effects where appropriate
- Foundry-ready item configuration
- Compendium organization

### User Interface

Custom character sheet additions and resource displays are being developed to better support mechanics specific to the Soul Society Supplement for 5e.
